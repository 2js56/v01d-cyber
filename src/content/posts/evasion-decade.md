> 这是一篇演化史备忘，不是武器库：文中代码全部是示意伪码，跑不起来的——省得你偷懒。

杀软与加载器的军备竞赛打了十年，攻防两端的思路各换了几个轮回。这篇按"时代"记一遍，给未来的自己（以及某个深夜里盯着进程树发呆的你）留一张地图。

## 时代零：明文年代

最古老的加载器长这样：

```c
// 伪码示意，勿抄
void *mem = VirtualAlloc(NULL, len, MEM_COMMIT, PAGE_RWX);
memcpy(mem, buf, len);
CreateThread(NULL, 0, (LPTHREAD_START_ROUTINE)mem, NULL, 0, NULL);
```

RWX 权限 + 明文落盘 + 单线程直接跑，特征扫描一抓一个准。这段代码今天仍活跃在各种入门教材里——以及各种蜜罐的告警日志里。

## 时代一：分离与混淆

检测方看特征，那就把特征藏起来：shellcode 加密存储、运行时解密、资源段分离、stager 分阶段拉取。这一代的胜负手是"落地瞬间"——解密发生在内存、载荷不落盘，静态扫描突然大面积失效。

于是检测方开始盯行为：进程注入、SetWindowsHookEx、APC 排队……"哪个正常程序会往别人内存里写代码？"

## 时代二：不再相信 ntdll

EDR 全面 hook ntdll 之后，攻方干脆绕开它：unhooking、直接 syscall。syscall 号从硬编码演化到运行时从合法模块里解析。这一代的哲学是——你 hook 的函数我不调了，我自己进内核。

## 时代三：内存里的伪装

现在的主战场在内存语义：内存属性欺骗（RW 与 RX 的切换时机）、模块伪造与 PE 雕刻、callback 式加载、线程上下文欺骗。检测方也升级到"看内存是否自洽"：可执行页有没有合法 PE 头、调用栈能不能回溯到合法模块、线程起点是否合理。

## 现在的战场

云查杀 + 行为模型 + 诱捕，单点免杀的性价比在下降。主流思路是全链路低噪声：初始访问、落地、横向、出网，每一环都"像正常流量"。这也是为什么防御侧的紫队演练越来越值钱——假设攻击者已经在里面，再去复盘每一环的可见性。

## 一点心得

- 免杀的尽头是工程：加密、加载、通信三件事的木桶效应，短板决定存活时间；
- 别迷信"某技术已死"的论调，死的是公开实现，思路总能借尸还魂；
- 写完加载器先过自家检测再说话——自己的靶场都骗不过，就别谈对抗了。

西比拉系统永远在测量你的心象，而常守朱要的是程序正义。攻防也是：检测方测量行为，攻方伪装语义——最后拼的是谁更理解"正常"二字的定义。
